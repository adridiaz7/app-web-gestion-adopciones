## T-04 · Registro de adoptante (solo API)
**Veredicto:** CAMBIOS SOLICITADOS

**Hallazgos:**
- **Importante** · `src/server/controllers/auth.ts:40` y `src/server/models/provinces.ts:4`
  - **Qué ocurre:** `provinceId` solo se valida como entero, pero `"Province".id` es `smallint`. Con un valor fuera de rango, como `99999` o `-40000`, PostgreSQL deduce que el parámetro es `smallint` y lanza el error `22003` ("valor fuera de rango para el tipo smallint"). Lo he comprobado con una consulta de solo lectura sobre `lagun_test`. La API responde entonces 500 "Ha ocurrido un error inesperado" en lugar de 400.
  - **Qué incumple:** la excepción de CU-01 "faltan datos obligatorios o tienen un formato incorrecto" debe dar un error de validación, no un error interno. Además, deja un error de la base de datos en el log por un dato del usuario.
  - **Cómo corregirlo:** acotar el rango en el esquema Zod (`.int().positive().max(32767)`, o mejor, el rango real de los códigos INE). Hay que añadir un test nuevo, por ejemplo `"CU-01: rejects a province id out of range"`, que espere un 400.
- **Sugerencia** · `src/server/controllers/auth.ts:50` y `src/server/middlewares/error-handler.ts:29`
  - **Qué ocurre:** con Express 5, si la petición llega sin cuerpo JSON (sin `Content-Type`), `req.body` es `undefined`. Zod devuelve entonces el campo `_` con su mensaje por defecto en inglés ("Invalid input: expected object…").
  - **Por qué importa:** los textos visibles para el usuario deben estar en castellano.
  - **Cómo corregirlo:** activar `z.config(z.locales.es())` o tratar ese caso con un mensaje propio.
- **Sugerencia** · `src/server/services/registration.ts:20` · El `as [number, number, number]` es seguro porque Zod ya ha validado la fecha. Aun así, una desestructuración con comprobación evitaría depender de un cast si `isAdult` se reutiliza desde otro sitio.

- **RN-06:** el email se guarda en minúsculas, con `ON CONFLICT` sobre `lower(email)`.
- **RN-07 y RN-177:** el token caduca a las horas configuradas y solo se guarda su hash SHA-256.
